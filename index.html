Informasi & Petunjuk Sistem

Selamat datang di E-EMAIL by All Education Indonesia. Ini adalah sistem pengiriman email massal berkecepatan tinggi dengan antrean paralel.

1. Kelola Master Kontak

Masukkan data karyawan atau penerima di menu Master Kontak. Bisa Manual / Import Excel.

2. Siapkan Template Pesan

Buat format pesan standar (seperti Payslip atau Info Umum) di menu Template Pesan.

3. Eksekusi Broadcast

Centang penerima, masukkan link lampiran (opsional), atur pengiriman langsung / terjadwal, lalu Kirim!

4. Fitur Slip Gaji

Gunakan menu Kirim Slip Gaji untuk merakit template tabel HTML Slip Gaji otomatis dari data Excel!
